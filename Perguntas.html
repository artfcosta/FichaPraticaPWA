Perguntas e Respostas sobre Git

Integração de Sistemas – Universidade Aberta

1 – O que são operações de “Commit”, “Push” e “Pop” efetuadas num repositório?

  • Commit guarda localmente uma “imagem” das alterações feitas aos ficheiros.
  • Push envia commits para o repositório remoto.
  • Pop pega nos ficheiros guardados e aplica as modificações na branch em uso.

2 – Quais são as vantagens de usar Branches num repositório Git?

Os branches permitem desenvolver funcionalidades ou correções de forma isolada, sem afetar o ramo principal.

3 – Nos Merges de conteúdos resultantes de um “Pop” podem resultar conflitos. Em que consistem e como podem ser resolvidos esses conflitos?

Um conflito acontece quando a mesma parte de um ficheiro foi alterada de forma diferente nas duas versões e o Git não sabe qual manter. O Git marca as zonas em conflito no ficheiro.

Para resolver:

  1. Edita-se o ficheiro;
  2. Escolhe-se o conteúdo final.

4 – “Clone” e “Fork” são formas diferentes de replicar um repositório Git. Quais as diferenças entre eles?

  • Clone é um comando que copia um repositório localmente no computador.
  • Fork permite criar uma cópia para a nossa conta, no caso do GitHub.
