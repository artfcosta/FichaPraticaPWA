1 - O que são operações de “Commit”, “Push” e “Pop” efetuadas num repositório?
    Commit guarda localmente uma uma "imagem" das alterações feitas aos ficheiros.
    Push envia commits para o repositório remoto.
    Pop pega nos ficheiros guardados e aplica as modificações na branch em uso.

2 – Quais sáo as vantagens de usar Branchs num repositório git?
    Branches permitem desenvolver funcionalidades ou correções de forma isolada, sem afetar o ramo principal.

4 – “Clone” e “Fork” são formas diferentes de replicar um repositório Git. Quais as
diferenças entre eles?
    Clone é um comando que copia um repositório localmente no computador.
    Fork permite criar uma cópia para a nossa conta no caso do github.
